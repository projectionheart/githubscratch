Checkout is handled securely by Stripe. We'll ask for your name, neighborhood and how to reach you so we can match you with a lounge. Buying a lounge buys you a piece of furniture — not shares, tokens, or a stake in CouchDAO, and there's no promise of any financial return.

The smart contract

It's a social contract, written smart.

  1. Hosts keep custody. A lounge never leaves a host's home without their say-so.
  2. Need beats queue. Requests are met by care, not first-come-first-served.
  3. Return it fluffier. Borrowers leave the lounge at least as nice as they found it.
  4. Anyone can exit. Hosts can stop hosting any time.
// CouchDAO.sol — illustrative, not deployed
contract CouchDAO {
  struct Lounge {
    address host;       // it lives here
    string  vibe;       // velvet? wicker?
    bool    available;
  }

  function borrow(uint id) external {
    require(needsRest(msg.sender));
    require(lounges[id].available);
    emit Reclined(msg.sender, id);
  }

  function needsRest(address)
    public pure returns (bool) {
    return true; // everyone does
  }
}
Questions

Before you recline.

Is this crypto?

No. The "smart contract" is a social one. Payments are ordinary card payments through Stripe, and nobody gets a token.

Who owns a lounge I buy?

You do. You can keep it at home, host it for the network, or both.

How do hosts get paid?

Hosts receive a share of the rental fee for each borrow of their lounge, paid out by CouchDAO.

What if I can't afford a rental?

Reach out anyway. This is mutual aid first.

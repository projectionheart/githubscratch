# The stitch

Fragments collected one a day, newest at the bottom. Each one is its own file, `YYYY-MM-DD-<slug>.md`, with a `# ` title, an optional `Type:` line and a *Stitches with* line linking the earlier fragments it connects to. Images and files live in `assets/YYYY-MM-DD-<slug>/`.

Things stitched together from several fragments are marked ⧉ and live on the site under `stitches/`.

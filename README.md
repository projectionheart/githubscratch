# githubscratch

A public journal on GitHub. Each commit is a small post that should be useful on its own.

**Prompt preview:** https://projectionheart.github.io/githubscratch/

## How it works

Every morning a prompt asks if there's anything to post today. Reply with text, images or files and it gets committed to `ideas/` as `YYYY-MM-DD-<slug>.md`. Attachments are saved in `ideas/assets/YYYY-MM-DD-<slug>/` and linked from the post (images show inline). Ignore the prompt and nothing happens.

## What to post

- **TIL**: one thing you figured out today, in a few lines.
- **Tiny demo**: a single-file HTML/JS sketch or effect. Link a live GitHub Pages version when you can.
- **Prompt that worked**: the exact prompt, what it produced and what you changed.
- **Teardown**: how a site, tool or effect you admired works, with your own diagram.
- **Before/after**: a design or code change shown side by side, with a line on why the second is better.
- **Opinionated list**: ranked tools, tricks or picks.
- **Open question**: something you haven't solved yet. Turn it into an issue to invite comments.
- **Weekly changelog**: what you built, learned and dropped this week.

## Making it social

- Pin this repo to your profile.
- Link your best posts from your profile README.
- Add topics like `til` or `generative-art` so people can find it.
